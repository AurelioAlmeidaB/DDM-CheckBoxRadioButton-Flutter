# CheckBox e RadioButton (Flutter)

App de cadastro de produto que mostra as cores e o tamanho escolhidos, feito em Flutter.

Versão em Flutter do [DDM-CheckBoxRadioButton](https://github.com/AurelioAlmeidaB/DDM-CheckBoxRadioButton), que foi feito em Kotlin.

## O que o app faz

- O usuário digita o nome do **produto**.
- Marca uma ou mais **cores** (Branco, Preto, Verde) com `Checkbox`.
- Escolhe um **tamanho** (Grande, Médio, Pequeno) com `RadioGroup`/`Radio`.
- Ao tocar em **Enviar**, o app mostra o produto, a lista de cores marcadas e o tamanho escolhido.
- Se nenhum tamanho for escolhido, aparece "Nenhum tamanho selecionado".

## Como rodar

```bash
flutter pub get
flutter run
```
